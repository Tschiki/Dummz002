# RC Musterstadt – Vereinswebseite

Statische Webseite für einen Rugbyverein (HTML, CSS, JavaScript – ohne Build-Tools).

## Aufbau
- `index.html` – alle Inhalte (Verein, Teams & Training, Spielplan, News, Mitgliedschaft, Sponsoren, Kontakt)
- `css/styles.css` – Gestaltung (Farben über CSS-Variablen in `:root` anpassbar)
- `js/main.js` – Mobile-Menü, Countdown, Spielplan-Filter, Formularprüfung
- `img/logo.svg` – Platzhalter-Logo

## Lokal ansehen
`index.html` direkt im Browser öffnen.

## Vor dem Livegang anpassen
- Vereinsname, Adresse, Kontaktdaten, Vorstand, Trainer, Beiträge (alles Platzhalter)
- Spielplan und News
- Kontaktformular: Versand benötigt ein Backend oder einen Formular-Dienst (siehe TODO in `js/main.js`)
- Impressum (Offenlegung nach § 25 MedienG / § 5 ECG) und Datenschutzerklärung (DSGVO) ergänzen
